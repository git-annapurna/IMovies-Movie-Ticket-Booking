# IMovies – Movie Ticket Booking System

## Project Overview
IMovies is a movie ticket booking application built using React.js, Node.js, and Express.js.

## Technologies Used
- Frontend: React.js, HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Storage: JSON file

## Features
- Browse movies
- Select seats
- Calculate ticket prices
- Confirm bookings and receive a Booking ID
- Save and retrieve booking records

## How to Run

### Backend
Open a terminal in the backend folder and run:
`npm install`
`node quickServer.js`

Backend runs on port 5001.

### Frontend
Open a terminal in the frontend folder and run:
`npm install`
`npm run dev`

Open the local address displayed by Vite.

## API Endpoints
- GET /api/movies
- GET /api/bookings
- POST /api/bookings
